# DRILL-09

pico2d 방향키 입력으로 소년을 이동시키는 2D 게임 프로그래밍 과제입니다.

## 실행 환경

- Windows, Python 3.14
- pico2d 1.5.1 (PySDL2, PySDL2-DLL 사용)
- 이 프로젝트에서는 `py -3.14` 인터프리터에 pico2d가 설치되어 있습니다.

필요하면 다음 명령으로 설치합니다.

```powershell
py -3.14 -m pip install pico2d==1.5.1
```

프로젝트 폴더에서 실행합니다.

```powershell
py -3.14 move_character_with_key.py
```

다른 폴더에서도 스크립트의 경로를 지정해 실행할 수 있습니다. 이미지는 스크립트가 있는 폴더에서 읽습니다.

## 조작과 동작

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동과 바라보는 방향 변경 |
| ↑ / ↓ | 상하 이동, 기존 좌우 바라보기 방향 유지 |
| 서로 다른 두 축의 방향키 | 대각선 이동 |
| ESC / 창 닫기 | 종료 |

- 키를 누르고 있는 동안 이동하고, 해제하면 해당 방향 이동을 멈춥니다.
- 같은 축의 반대 방향키는 서로 상쇄됩니다. 한쪽만 떼면 남은 방향으로 이동합니다.
- 실제 이동하면 달리기, 정지하면 IDLE 애니메이션을 반복합니다. 좌우 방향에 맞는 스프라이트를 사용합니다.
- 화면 가장자리에서 캐릭터 전체가 화면 안에 머뭅니다. 벽 쪽으로만 입력하면 IDLE 상태가 됩니다. 움직임이 막혀도 수평 입력으로 바라보는 방향을 바꿀 수 있습니다.
- 직선과 대각선의 이동 속도는 100px/s입니다. 벽에 막힌 대각선 입력은 남은 축을 다시 정규화하지 않으므로 약 70.71px/s로 벽을 따라 이동합니다.
- 애니메이션은 8프레임, 프레임당 0.05초입니다. 상태 또는 좌우 방향이 바뀌면 첫 프레임부터 시작합니다.
- 창이 포커스를 잃으면 누른 키 상태를 초기화합니다. 복귀 후 방향키를 새로 눌러 이동합니다.

## 파일과 참고 자료

- `move_character_with_key.py`: 과제 구현과 실행 파일.
- `animation_sheet.png`: 과제 제공 캐릭터 시트, 100×100 셀과 8프레임 사용.
- `TUK_GROUND.png`: 과제 제공 1280×1024 캠퍼스 배경.
- `character_runs_esc.py`, `move_character_with_mouse.py`: 기존 강의 예제 골격.
- [PLAN.md](./PLAN.md): 강의 내용을 적용한 설계, 커밋 순서와 제출 체크리스트.
- [TEST_CHECKLIST.md](./TEST_CHECKLIST.md): 재현 절차와 실제 검증 결과.

입력 처리의 참고 자료는 로컬 `LEC10_입력처리.pdf`입니다. 강의 PDF는 원격 저장소에 포함하지 않았습니다. 제공받은 이미지와 강의 예제는 학습 과제에 사용했습니다.
