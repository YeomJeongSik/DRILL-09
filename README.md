# DRILL-09

pico2d 방향키 입력으로 소년을 이동시키는 2D 게임 프로그래밍 과제입니다.

## 실행 환경

- Windows, Python 3.14
- pico2d 1.5.1 (PySDL2, PySDL2-DLL 사용)
- 이 프로젝트에서는 `py -3.14` 인터프리터에 pico2d가 설치되어 있습니다.

필요하면 다음 명령으로 설치합니다.

```powershell
py -3.14 -m pip install pico2d==1.5.1
```

프로젝트 폴더에서 실행합니다.

```powershell
py -3.14 move_character_with_key.py
```

구현 단계와 확인 기준은 [PLAN.md](./PLAN.md)를 참고하세요.
